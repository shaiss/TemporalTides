# Core Gameplay Loop

**Part IX: Gameplay Mechanics**

---

## Overview

Temporal Tides is a character-switching puzzle-action game where players experience time differently through each character's perception, solve temporal puzzles using unique neuro-temporal abilities, and build team synergies to confront escalating threats.

---

## Primary Loop

```
Explore Zone → Encounter Challenge → Switch Character → Solve/Fight → Progress → Reflect
```

### 1. Explore Zone
- Navigate temporal zones (each with distinct RFR and properties)
- Current character shapes perception (visual, audio, pacing)
- Discover points of interest, NPCs, intel
- Temporal properties affect navigation

### 2. Encounter Challenge
- Puzzles (temporal, perception-based, team-coordination)
- Combat (rare; Vibrion/Eli primary)
- Social (Dave's empathy; Anne's strategy)
- Narrative (dialogue, choices, discovery)

### 3. Switch Character
- Core mechanic: switch active character to change perception and abilities
- World visually/audibly shifts to reflect new character's experience
- Each challenge has multiple valid approaches (character-dependent)

### 4. Solve/Fight
- Apply character ability to challenge
- Some puzzles require single ability; some require sequential switching
- Team puzzles: multiple characters coordinate (player manages sequence)

### 5. Progress
- Story advances
- Character relationships deepen
- New abilities/refinements unlock
- New zones accessible

### 6. Reflect
- Dr. Mental sessions (optional; character development)
- Journal entries (character voice)
- Relationship moments

---

## Character Switching

### Mechanic
- Player can switch between available characters at will (outside combat)
- Each switch changes: visual perception, audio, available abilities, interaction options
- Some areas restrict switching (narrative moments; solo challenges)

### What Changes on Switch

| Element | Effect |
|---------|--------|
| Visuals | RFR perception, color palette, HUD |
| Audio | Character theme, soundscape modulation |
| Movement | Speed, rhythm (Eli fast; Dave slow) |
| Interactions | Ability-specific options appear |
| Dialogue | Character voice for narration/internal |

---

## Progression Systems

### Ability Development
- Abilities improve through use and story
- Not skill trees; organic growth (practice → mastery)
- Dr. Mental sessions unlock emotional growth (gating mechanism)

### Relationship Building
- Team interactions between missions
- Dialogue choices affect dynamics
- Synergy abilities unlock at relationship thresholds

### Zone Access
- Story progression opens new zones
- Some zones require specific character abilities to enter
- Optional exploration rewards (lore, cosmetic, backstory)

---

## Difficulty and Accessibility

### Adaptive Difficulty
- Puzzle hints after time threshold
- Combat difficulty adjustable
- No failure state for accessibility mode (retry without penalty)

### Neurodiversity-Informed Design
- Multiple solutions per challenge (different abilities = different approaches)
- Pacing adjustable (rush vs. contemplate)
- Sensory options (reduce visual/audio intensity)
- Communication clarity (literal subtitles, symbol support)
